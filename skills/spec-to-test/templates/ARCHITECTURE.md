API tests with Playwright + TypeScript, on the testware-core boilerplate (`HttpClient` → `PlaywrightHttpClient`, `ContractValidator` with AJV).

## Layers

| Layer | Where | Convention | Example |
|-------|-------|------------|---------|
| HTTP | `core/http/` | `HttpClient` is the abstraction; `PlaywrightHttpClient` is the only one that uses `APIRequestContext` | `core/http/HttpClient.ts` |
| Config | `core/config/<File>.ts` | `config.<key>` read from `.env.<ENV>`; required key with `required(...)` | |
| Contract | `<schemas folder>/<Name>Schema.ts` | AJV schema, `additionalProperties: false`, validated with `ContractValidator.validate(schema, body)` | |
| Types / models | `<folder>/` | `<Method><Resource>Body`, `<Method><Resource>Response`; enums as string unions; builder when there is one | |
| Interface | `<folder>/<Domain>Interface.ts` | PascalCase methods `<Method><Resource>(...)` | |
| Service | `services/<Domain>Service.ts` | `implements` the interface, receives `HttpClient` in the constructor, no assertions | |
| Fixtures | `<fixtures/ApiFixtures.ts or tests/baseTest.ts>` | Provides an authenticated service/client; exports `test` and `expect` | |
| Helpers | `tests/helpers/<domain>/` | Test data setup, multi-call flows, reusable `expect*` | |
| Specs | `tests/<domain>/<operation>.spec.ts` | Import `test`/`expect` from the fixture, never from `@playwright/test`; tests only | |

## Test specs

- Title: `<PREFIX>-NN: <description>` (the ID links the test to the spec case)
- Comment header with the feature spec version `(vX.Y.Z)` and a summary of the rule
- `test.step` for each phase of the case (setup, action, verification)

## Async and state

- Waiting for status: `expect.poll(...)` or `expect(...).toPass({ timeout })`, with an explicit timeout. `waitForTimeout` only for a fixed window to prove something did **not** happen.
- `fullyParallel`: <yes/no>. Specs with shared state use `test.describe.configure({ mode: "serial" })`.
- Effects are observed through: <API only | database | queue | ...>
